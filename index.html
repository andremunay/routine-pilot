Independent local copies

Share a routine by link, QR, or file.

Links and QR codes carry an authored snapshot in the URL itself. The browser preview decodes it on your device; each explicit import creates an independent editable copy. No account, hosted routine lookup, revocation, or update service is involved.

Anyone with the complete link can read it. Links exclude custom sounds and Library metadata. Use file transfer when a routine includes custom audio.
